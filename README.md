# TastyBites — Restaurant Website

A responsive restaurant website built for our **LA-II Mini Project** using **HTML5** and **Bootstrap 5**, designed first in **Figma**.

## Features & Sections
- **Navigation & Menu:** Restaurant navigation and featured menu highlights.
- **Table Booking:** Interactive table reservation section (<section id="booking">).
- **Chef's Specials:** Highlighted dishes and combo offer arranged in a responsive grid.
- **Customer Reviews:** Customer feedback cards paired with a featured center graphic.

## Built With
- HTML5
- Bootstrap 5
- Figma (UI/UX Prototype)
